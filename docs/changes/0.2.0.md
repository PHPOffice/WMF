# 0.2.0

## Enhancements

- Added support for EMF files (`PhpOffice\WMF\Reader\EMF`) in [#9](https://github.com/PHPOffice/WMF/pull/9) by [@Progi1984](https://github/Progi1984)
- Added detection of the type of an image (`PhpOffice\WMF\Reader\Detector`) in [#9](https://github.com/PHPOffice/WMF/pull/9) by [@Progi1984](https://github/Progi1984)
- Added method `isSupported` to readers in [#9](https://github.com/PHPOffice/WMF/pull/9) by [@Progi1984](https://github/Progi1984)
- `PhpOffice\WMF\Reader\WMF\GD` : Uses the renderer of EMF files (texts, curves, regions, clipping, bitmaps, antialiasing...) in [#9](https://github.com/PHPOffice/WMF/pull/9) by [@Progi1984](https://github/Progi1984)
- Added support for EMF+ files (`PhpOffice\WMF\Reader\EMF\GD`) by [@Progi1984](https://github/Progi1984)

## Bug fixes

- `PhpOffice\WMF\Reader\WMF\Magic` : Use the next backend if Imagick doesn't support WMF files in [#9](https://github.com/PHPOffice/WMF/pull/9) by [@Progi1984](https://github/Progi1984)

## Miscellaneous

- Added support for PHP 8.4 & 8.5 in [#8](https://github.com/PHPOffice/WMF/pull/8) by [@Progi1984](https://github/Progi1984)
- Readers : Added a common abstract class `PhpOffice\WMF\Reader\ReaderAbstract` & common traits (`PhpOffice\WMF\Reader\GDTrait`, `PhpOffice\WMF\Reader\ImagickTrait`, `PhpOffice\WMF\Reader\MagicTrait`) in [#9](https://github.com/PHPOffice/WMF/pull/9) by [@Progi1984](https://github/Progi1984)
- Added a renderer shared by GD readers (`PhpOffice\WMF\Renderer`) in [#9](https://github.com/PHPOffice/WMF/pull/9) by [@Progi1984](https://github/Progi1984)
